# Employee Performance Evaluation System

A web-based application for managing employee information and performance records.

## Technologies Used

- Java
- Jakarta Servlets and JSP
- HTML and CSS
- MySQL
- JDBC
- Maven
- Apache Tomcat

## Completed Features

- Add employee records
- View the employee directory
- Edit employee information
- Delete employee records
- Responsive interface for desktop and mobile screens
- Display success messages after CRUD operations
